# Calculadora Fetico Moderno — nacimiento y adopción

Web estática para GitHub Pages.

## Correcciones de esta versión
- Todas las fechas se introducen en formato español `DD/MM/AAAA`, evitando los controles de fecha dependientes del idioma del navegador.
- La fecha de lactancia toma como referencia la reincorporación del último periodo de nacimiento seleccionado con semanas superiores a cero.
- Los días laborables/horas de lactancia se calculan desde esa reincorporación hasta los 9 meses.
- Se mantienen las opciones, desplegables, reducción de jornada, periodos, Pebbles y logotipos de la versión completa.

## Publicación
Sustituye los archivos del repositorio por los de este paquete y conserva la carpeta `assets`. GitHub Pages debe publicar desde la rama `main`, carpeta `/ (root)`.
